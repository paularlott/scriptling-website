# Getting Started

Scriptling can be used two ways: as a standalone command-line tool, or embedded inside a Go application. Choose the path that's right for you.

- [Using the CLI](https://scriptling.dev/okf/scriptling-docs/quick-start/cli.md) — Install the Scriptling CLI and start running scripts from the command line. Includes interactive mode, HTTP server, and MCP server capabilities.
  - Install on macOS, Linux, or Windows
  - Run scripts, use the REPL, or start a server
  - No Go knowledge required
- [Embedding in Go](https://scriptling.dev/okf/scriptling-docs/quick-start/embedding.md) — Add scripting capabilities to your Go application. Register libraries, exchange variables, and create custom extensions.
  - Single dependency, minimal binary size
  - Register built-in or custom libraries
  - Sandboxed execution with configurable security
- [VSCode Extension](https://scriptling.dev/okf/scriptling-docs/quick-start/vscode.md) — Get syntax highlighting and language support for Scriptling in Visual Studio Code.
  - Syntax highlighting
  - Language support
- [Documentation MCP](https://scriptling.dev/okf/scriptling-docs/quick-start/documentation-mcp.md) — Serve Scriptling's documentation to AI agents as OKF knowledge bundles through an MCP server.
  - Browse and search docs from any MCP client
  - Semantic and keyword search
  - Run over stdio or HTTP
