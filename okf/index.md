# Scriptling OKF Bundles

OKF 0.2 knowledge bundles generated from the [Scriptling documentation](https://scriptling.dev/docs/). Fetch these URLs directly: every document is plain markdown with YAML frontmatter, and every link is an absolute https://scriptling.dev/okf/ URL, so no relative-path resolution is ever needed. [llms.txt](https://scriptling.dev/okf/llms.txt) lists every page in one fetch. The release zip keeps portable relative links per OKF §5.2.

## Bundles

- [scriptling-docs](https://scriptling.dev/okf/scriptling-docs/index.md) — Guides: quick start, CLI usage, Go integration, plugins, security, and tutorials.
- [scriptling-reference](https://scriptling.dev/okf/scriptling-reference/index.md) — Language reference: syntax, types, operators, control flow, functions, classes, and error handling.
- [scriptling-libraries](https://scriptling.dev/okf/scriptling-libraries/index.md) — API reference for every standard, Scriptling, and extended library.
