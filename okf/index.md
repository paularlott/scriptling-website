# Scriptling OKF Bundles

OKF 0.2 knowledge bundles generated from the [Scriptling documentation](https://scriptling.dev/docs/). Fetch these URLs directly; every document is plain markdown with YAML frontmatter and relative links.

## Bundles

- [scriptling-docs](scriptling-docs/index.md) — Guides: quick start, CLI usage, Go integration, plugins, security, and tutorials.
- [scriptling-reference](scriptling-reference/index.md) — Language reference: syntax, types, operators, control flow, functions, classes, and error handling.
- [scriptling-libraries](scriptling-libraries/index.md) — API reference for every standard, Scriptling, and extended library.
